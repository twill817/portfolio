Dead Derby

Mobile game · In progress

A zombie physics runner for iPhone and Android that I'm building completely on my own. I don't write code, so it's a fairly honest test of how far design skills and AI tools can take one person.

The game runs in Unity. I make the 3D models with Tripo and Blender, use AI image generation for artwork and references, and work through the code with Claude and Google Antigravity. Early on I settled on one-finger controls. The design doc is still a work in progress, and so is the game.

This site

Website · Live

I designed and built this portfolio with Claude Code, and it runs on GitHub Pages. Along the way it picked up a few things a portfolio doesn't usually have: a private review mode, where invited reviewers leave comments only I can read, and a weekly analytics report that pulls itself together every Monday morning.

It's also been good practice at something I ask of teams: put a real thing in front of people early and let their feedback shape it.

Paper trading

Experiment · Running

A simulated stock portfolio, with no real money, that buys and sells on its own once a week for a few months. It started with $10,000, split between long-term holdings and a smaller portion it trades more actively. Claude does the market research and makes the calls, and a dashboard tracks how it's doing.

I'm not interested in day trading. What I want is the reasoning: why each stock was bought or sold, which trends it's following, and whether those calls hold up against history.
